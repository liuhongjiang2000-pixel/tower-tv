# 都市盖楼（Tower TV）

开源的**叠塔类单机小游戏**，致敬诺基亚经典《都市摩天楼》（City Bloxx）：吊机吊着楼层块左右摆动，按确认键落下，对得越齐楼越高，偏太多就塌。为电视大屏与遥控器操作设计，单键可玩。

## 玩法

- 楼层块随吊钩左右摆动，**按确认键（OK）或触屏点按**落下
- 与下层对齐的部分保留，多出的部分被切掉坠落
- **完全对齐**触发"完美"连击，得分加成
- 重合太少 → 楼塌，显示层数与得分
- 摆动速度随层数加快

## 操作

| 按键 | 作用 |
| --- | --- |
| 确认键 / 回车 / 方向下 | 落块；结算后重开 |
| 触屏点按 | 同上 |

## 构建

GitHub Actions 在 `main` 分支推送时自动构建并发布到 [Releases](https://github.com/liuhongjiang2000-pixel/tower-tv/releases)。

本地构建：JDK 17 + Gradle 8.9 + Android SDK 34，`gradle assembleDebug`。
